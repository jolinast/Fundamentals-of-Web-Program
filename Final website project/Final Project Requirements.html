Students must demonstrate proficiency in writing and commenting valid HTML and CSS code, ensuring to utilize advanced features such as flexbox and grid layouts to create dynamic, responsive, and visually engaging web interfaces. 

This is a competency-based assessment. Students can submit it as many times as needed. There will be an end-of-term standardized traditional online assessment on the final exam date.

Developing (D) - Student creates a website that includes 70% or fewer of the following:

HTML

- id attributes identify unique elements. class attributes identify reusable elements.

- A header HTML file contains a site title and navigation. This file must contain nav, ul, li, and a elements. The site title can be an h1 heading or img logo. Navigation includes at least four buttons. One button contains a drop-down menu. One button contains a mega menu.

- A footer HTML file contains navigation, social media icons, and copyright information. This file must contain nav, ul, li, and a elements.

- A header element is added after the opening body tag and a footer element is added before the closing body tag in all HTML files. JavaScript/jQuery is used to dynamically include the header and footer HTML content.

- Banner/Jumbotron HTML on the homepage includes heading text, paragraph text, and a call-to-action button.

- At least two HTML sections are displayed between the homepage banner and footer, and wrapped inside main tags. Each section has SVG dividers above and below. Each section has a div container with two columns of content (i.e., image/video in the left column, heading and text in the right column, or vice versa).

- Icon images are used as needed for the favicon, site title, main content, or footer social media links.

- Sidebar content is added to display next to the main content.

- At least three supplementary pages include at least one HTML section displayed between the header and footer, and wrapped inside main tags. Each section has a div container with at least one grid layout, table, or form.

- The student adds at least one creative HTML content that was not taught in class.

- All HTML files are successfully validated.

- All HTML files follow accessibility rules.

- All HTML files are deployed to a live web server.

- All images display, links work, and no placeholder content exists.

CSS

- Demonstrate exceptional proficiency in crafting efficient, clean, and sophisticated CSS style sheets that fully leverage CSS capabilities to enhance the visual appeal and user experience of web pages.

- Style sheets are meticulously organized and commented on, with clear descriptions of styles, layout decisions

- At least one font library is imported. Fonts are creative and easy to read. Font sizes are appropriate.

- CSS reset styles are included.

- At least five root color variables are included.

- CSS contains at least one of each of the following selectors: wildcard (*), element (body), id (#banner), class (.container), child (header > ul), descendent (header li), multi element (header, main, footer), adjacent sibling (h2 + p), general sibling (h2 ~ p) pseudo class (:first-child, :last-child, :nth-child, :nth-last-child, :nth-of-type, :nth-last-of-type, etc.)

- Padding, margin, and borders are added appropriately. Padding and margin are applied using 1-4 values.

- Container styles ensure content never touches the border of its parent container.

- Box shadows are added appropriately.

- Expertly utilizes CSS animations and transitions to create visually engaging web interfaces.

- Expertly utilizes flexbox and grid layouts to create dynamic and responsive web interfaces.

- Hyperlinks and buttons have hover styles applied.

- Header and footer content are styled horizontally using flexbox.

- Banner/Jumbrotron styles include a full-width background image. The heading, paragraph, and call-to-action button are styled vertically using flexbox.

- SVG dividers are styled appropriately.

- Header navigation is responsive. Buttons display horizontally on desktop view and are replaced on mobile view with a hamburger menu that opens the navigation when clicked. Dropdown and megamenu styles are applied on desktop view.

- Main content sections and sidebars are responsive. They display horizontally on desktop view and vertically on mobile view.

- Grid styles are appropriate and responsive. Content displays in rows and columns on desktop view and vertically on mobile view.

- Table styles are appropriate and responsive.

- Form styles are appropriate and responsive.

- The student adds at least one creative CSS content that was not taught in class.

- All CSS files are successfully validated.

- All CSS files follow accessibility rules.

- All CSS files are deployed to a live web server.
