HTML and CSS Textbook

The book we are using is Murach's HTML and CSS, 6th Edition, by Zak Ruvalcaba and Anne Boehm. It can be purchased from the Kirkwood Bookstore.

Videos in each of the "Course Materials" modules are based on textbook content. You will be assigned weekly reading and coding assignments from this book.
