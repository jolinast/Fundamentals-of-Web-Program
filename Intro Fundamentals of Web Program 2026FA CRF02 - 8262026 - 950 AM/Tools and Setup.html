Hardware Requirements

For in-class students: You may use your personal laptop or a school computer. For online-only students: You must use your personal laptop computer. 

Any personal computer manufactured in the last five years is preferred for this course. Microsoft Windows 11 or later, macOS Mojave (version 10.15) or higher, or any Linux distribution (for example, Debian or Ubuntu) is acceptable. ChromeOS can be used, but note that some of the software requires you to have administrative rights on your device. If you do not have administrative rights, you will need to use web-based development tools.

A working microphone will be needed for assignments that require screen recording.

Storage Requirements

If you plan to use a classroom computer, please use a cloud storage service (Microsoft OneDrive, Google Drive, Dropbox, etc.) or bring a portable storage drive to save your work. Students are responsible for backing up their projects and data to prevent loss.

Dual Monitor

If you use a personal laptop, I highly recommend using a second monitor to improve productivity. Consider purchasing a portable monitor or connecting an HDMI cable from your laptop to a school monitor.

Online and In-Person MacOS Users

Install Homebrew

  • Open the Terminal app.
  • Run the command which brew to determine if you have the Homebrew package manager already installed.
    • If Homebrew is not installed, no message will display. Please install it by running this command:
      /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
      • You may need to agree to install XCode Command Line Tools, which is necessary for installing Homebrew.
    • If Homebrew is installed, you will see some text like "/usr/local/bin/brew" followed by the command prompt on the next line. In this case you should update Homebrew by running this command:
      brew update
      • Follow any prompts it may give you to upgrade existing packages.
  • To verify Homebrew is installed correctly, run the following command:
    brew doctor
    • You're good if you see something like: "Your system is ready to brew."
    • You need to try again if you see something like: "-bash: brew: command not found".

Install VS Code

  • Download VS Code. VS Code is a free and powerful Integrated Development Environment (IDE) for Python and many other programming languages.
  • Extract the zip file and move the app to your Applications folder.
  • Open VS Code, click View | Command Palette, Type and select "Shell Command: Install 'code' command in PATH". Close and restart the program.
  • Install the "Live Server" extension.
    • For additional details on installing extensions, see Extension Marketplace.

Check Installations

Open Git Bash (Windows) or the Terminal App (Mac). Git Bash and the Terminal are apps that run a Unix shell. A Unix shell is a command line user interface between you and your computer's operating system. In a Unix shell, you can type in commands that tell the computer to do many things: navigate to files and folders, install and run programs, and change configurations. Programmers rely on their Unix shells to do lots of work quickly and easily.

Type the following commands one at a time to see what you have installed from the previous course. 

Commands to verify installations
Command Notes

git --version

Displays the installed version of Git.

code -v

Displays the installed version of the VS Code.

git config --global core.editor "code --wait"

Establishes VS Code as the default text editor.

git config --global user.name "YOUR FULL NAME"

Replace "YOUR FULL NAME" with your full name.

git config --global user.email "YOUR EMAIL ADDRESS"

Replace "YOUR EMAIL ADDRESS" with the primary email from your GitHub account.
